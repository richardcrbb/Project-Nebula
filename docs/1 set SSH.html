Set up SSH login with key-based authentication.

It is essential to protect your server against potential attacks. Using SSH key-based autehntication is an important security feature that helps safeguard your system. By disabling password-based autehntication, you prevent intruders from attempting brute-force attacks to gain access to your server.

In the previous tutorial, you installed an Ubuntu Server image, which already includes an OpenSSH server. This is why you were able to connect using a user's password. Now, from your client PC, you will create an SSH key pair, which consists of a private key and a public key. The private key must remain on the client machine because it contains sensitive information that identifies you as the legitimate client expected by the server. The public key, on the other hand needs to be copied to the server. The server uses this public key to verify your private key during authentication. If they match, you are granted access.
