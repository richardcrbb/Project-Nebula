PI-HOLE

In this tutorial, we will set up a fully functional Pi-hole service using a Docker container. Pi-hole is a network-level DNS server that resolves domain names to IP addresses, similar to an address directory. One of its main features is the ability to block ads: you can add lists of known ad-serving domains, and Pi-hole will redirect requests to these domains to a non-routable IP (0.0.0.0), effectively preventing connections. Additionally, Pi-hole allows you to define custom DNS entries for your containers or devices, ensuring they resolve to specific IPs within your network. Essentially, it works as both an ad blocker and a customizable DNS server for your infrastructure.

Custom Domain Names

      
You can create custom domain names for your services to simplify and streamline access. These domains can point directly to the IP address of a 
        container within the tailscale-vpn Docker network or to any device in your tailnet. Since all nodes and services are connected through the tailnet, 
        everything remains securely reachable from any authorized device.

      
To create a custom domain for a service you go to:

      
Settings => Local DNS Records

      
In this section, you can create a custom domain name by specifying your domain and the IP address of the target service or device.

      
Let's create the domain pihole.nube for the ip address 10.10.10.2

      
Log out from your pihole and open a new browser tab using:

      
pihole.nube/

      
Remember to include a trailing “/” at the end of the domain the first time you access it in your browser. This helps the browser recognize 
        it as a valid domain rather than a search query. After the initial visit, you can access the domain normally without the “/”.
      

      
Have in mind that specifically for Pi-hole, it serves it's interface in the route /admin/ so you can add it when typing your domain in your browser. 
        Do not add 10.10.10.2/admin/ directly, as this is not a valid ip, just type it in the web browser:
      

      
pihole.nube/admin/

      
For other services you normally would do:

      
YOUR-CUSTOM-DOMAIN-/
