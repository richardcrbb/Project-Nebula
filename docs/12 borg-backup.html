Borg-Backup

Move your data to other physical storage device

Create a borg-repo in the backup device:

sudo borg init \
  --encryption=repokey-blake2 \
  /mnt/hdd2tb/borg-repo

Save the key:

sudo borg key export /mnt/hdd2tb/borg-repo ~/borg-key-rescue.key

Make the first backup:

sudo borg create \
  --stats \
  --progress \
  --compression lz4 \
  /mnt/hdd2tb/borg-repo::init-$(date +%Y-%m-%d) \
  /mnt/rescue

Check the integrity:

sudo borg check /mnt/hdd2tb/borg-repo
