Subnet Setup

In this tutorial, we will configure the server to enable IP forwarding through the host kernel, allowing it to route and retransmit network traffic between interfaces. Additionally, we will create a custom Docker subnet to isolate our services, providing full control over container networking and port management. This setup improves network segmentation, security, and flexibility when deploying containerized applications.
